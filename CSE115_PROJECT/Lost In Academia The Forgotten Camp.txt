Lost In Academia: The Forgotten Campus 🎓👻

A terminal-based text adventure game built in C. This was created as a final project for CSE115, exploring file handling, structs, array manipulation, and game state management.


📖 The Story

You are a freshman at NSU. A rumor says there's an old, hidden campus. One night, you find a hollow-sounding wall in the basement... A hidden door opens, and you step inside the forgotten campus.

To escape, you must explore rooms, solve riddles about university life, gather 6 lost items, and survive the Final Exam.


✨ Features

User Accounts: Register, login, and delete profiles using binary file saving (users.dat).

Game Saves: Your progress and inventory are automatically saved. You can quit at any puzzle and resume later.

Text Adventure:

Riddle-based exploration.

A multi-item pedestal puzzle requiring logical deduction.

A final exam mechanic that tests your game knowledge.

Cross-Platform: Compiles seamlessly on Windows (MSVC/MinGW), macOS, and Linux.


🚀 How to Run


1. Compile the Game

Make sure you have a C compiler installed (like GCC). Open your terminal/command prompt and run:

gcc LostinAcademiaMasterCode.c -o game


2. Play

Run the compiled executable:

On Windows:

.\game


On macOS/Linux:

./game


🎮 How to Play

Navigate main menus using numeric keys (1, 2, 3).

When presented with a riddle, type your answer and press Enter.

Type quit during any input prompt to save your game and exit immediately.
